# Убийца Скроллинга — версия для GitHub Pages

Это публичная версия игры для телефона. У каждого игрока свой прогресс на устройстве и в отдельной записи игрового сервера. Репозиторий содержит только код и изображения игры: личные данные игроков в него не входят.

## Установка на iPhone

1. Откройте ссылку игры в Safari.
2. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
3. Откройте игру с новой иконки. После первого запуска с интернетом основные файлы сохранятся для работы без сети.

## Как играть

- «Таймер» → «Начать чтение»: через 10 минут нажмите «Завершить и получить награду».
- «Занятия»: отмечайте выполненное и получайте леденцы.
- «Коллекция»: покупайте локации и предметы за леденцы. Предмет можно снять повторным нажатием.

У владельца игры уже есть настроенная команда ScrollKiller. После восстановления его личной копии с ключом игра на GitHub Pages получает данные через защищённый мост к прежнему серверу. Команду на iPhone менять не нужно: урон за Instagram, TikTok, YouTube и VK продолжает начисляться автоматически после отправки отчёта.

У каждого нового игрока автоматически создаётся свой личный код и отдельное сохранение. Для учёта Экранного времени откройте в игре «Настройки» → «Прогресс и iPhone», скопируйте личный код и установите общую команду ScrollKillerFriends из этого раздела. При установке вставьте свой код. Первый запуск команды задаёт исходную точку: старые минуты не отнимают здоровье. Затем в приложении «Команды» создайте автоматизацию «Приложение → Закрыто» для Instagram, TikTok, YouTube и VK, которая запускает ScrollKillerFriends. После выхода из этих приложений команда отправит отчёт; игра заберёт его при открытии и раз в минуту во время работы. У каждого игрока свои минуты и свой прогресс.

Без команды можно играть с таймером, занятиями и коллекцией. Кнопки синхронизации и настройки видны всем, чтобы подключить iPhone позднее. Личный код и файл сохранения не передавайте другим игрокам.

## Резервная копия прогресса

1. В игре откройте «Настройки» → «Скачать копию».
2. Сохраните JSON-файл в «Файлы» на iPhone.
3. Для второй копии загрузите этот файл в **приватный** репозиторий GitHub или сохраните в личных «Файлах». Файл содержит личный ключ синхронизации. Не добавляйте его в публичный репозиторий игры и не отправляйте другим игрокам.
4. Для восстановления откройте «Настройки» → «Восстановить из файла» и выберите JSON.

Safari и иконка «На экран Домой» могут хранить данные раздельно. При переходе между ними переносите сохранение через JSON-файл.

## Обновление сайта

В исходном проекте выполните `node build-pages.mjs`. Готовые файлы будут в `dist/pages/`. На GitHub Pages публикуется содержимое этой папки. При обновлении файлов прогресс на телефонах игроков не сбрасывается.
